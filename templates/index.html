Model Architecture

FT-Transformer classification head with multi-stage feature projection. Implemented via an optimized feedforward network for sub-second real-time inference latency.

  • Input Dimension: 360 multimodal features
  • Perm Slots (0–199): 200 Android permissions (weighted)
  • API Slots (200–349): 150 DEX API & Ad SDK signatures
  • Metadata Slots (350–359): 10 normalized package attributes
  • Hidden Layers: Dense 256 → 128 → 64 (ReLU)
  • Output: Softmax over 3 classes (Benign, Adware, Malware)
  • Optimizer: Adam with adaptive learning rate

Research Foundation & Literature Grounding

AdwareGuard architectural decisions are grounded strictly in the following peer-reviewed journal articles and preprint:

  1. [1] Ullah, Farhan, et al. "Explainable malware detection system using transformers-based transfer learning and multi-model visual representation." Sensors 22.18 (2022): 6766.
    → Basis for attention-based explainability module surfacing per-feature importance scores alongside verdicts.
  2. [2] Almakayeel, Naif. "Deep learning-based improved transformer model on android malware detection and classification in internet of vehicles." Scientific Reports 14.1 (2024): 25175.
    → Basis for the 3-class classification head design and rigorous multi-metric evaluation (Accuracy, Precision, Recall, F1, AUC-ROC).
  3. [3] Bavishi, Shrey, and Shrey Modi. "Accelerating malware classification: A vision transformer solution." arXiv preprint arXiv:2409.19461 (2024).
    → Basis for using lightweight inference stages to maintain sub-second latency in production web scans.
  4. [4] Tanveer, Muhammad Usama, et al. "Graph-augmented multi-modal learning framework for robust android malware detection." Scientific Reports 15.1 (2025): 38341.
    → Basis for multimodal fusion of permissions, DEX APIs, and metadata into a unified 360-dim representation.
  5. [5] Alshomrani, Mohammed, et al. "An Explainable Hybrid CNN–Transformer Architecture for Visual Malware Classification." Sensors 25.15 (2025): 4581.
    → Basis for pairing the classifier with an interpretable feature attribution layer rather than a black-box verdict.
